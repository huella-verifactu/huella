# Security policy

`huella` computes the hashes and builds the records that Spanish businesses send to the Tax
Agency, so a bug here can have legal consequences for its users. Please report security problems
privately.

## How to report

Use GitHub's private vulnerability reporting: the **Security** tab of this repository →
**Report a vulnerability**. Do **not** open a public issue, discussion or pull request for a
security problem.

Please include the affected version, a description of the problem and, if possible, a minimal
reproduction. Never send real certificates, keys or taxpayer data.

## What to expect

- An acknowledgement within **72 hours**.
- An assessment and a plan within 7 days.
- A fix released, and the advisory published, within **90 days** of the report at the latest
  (coordinated disclosure). We credit reporters unless they prefer otherwise.

## Supported versions

Only the latest release receives security fixes while the project is in `0.x`.
